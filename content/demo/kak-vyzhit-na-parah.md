# Как выжить на парах

> Главное правило: приходить. Остальное — детали.

## Утро

1. Будильник ставится на 20 минут раньше, чем кажется нужным.
2. Эти 20 минут уходят на «ещё пять минут».
3. Дальше — бегом, но с достоинством.

## Что брать с собой

| Вещь | Зачем |
| --- | --- |
| Тетрадь | чтобы было куда не писать |
| Ручка | одна, но своя |
| Зарядка | телефон важнее конспекта |
| Донер | топливо |

## Код выживания

```python
while пары:
    if не_выспался:
        кофе()
    конспектировать()
```

## Вывод

Если пришёл, уже молодец. Если ещё и записал — вообще герой.
